## 🚀 Featured Projects

### 🛡️ Sentinel-Agent

**AI-assisted, evidence-based access-control penetration testing tool**

A security testing tool designed to detect authorization vulnerabilities
such as:

- IDOR / BOLA
- BFLA
- BOPLA
- BOLA write vulnerabilities
- Reflected XSS
- Error-based SQL Injection

The architecture separates AI reasoning from vulnerability verdicts:
the LLM proposes hypotheses, while deterministic components validate
findings and produce reproducible evidence.

**Tech:** Python · Docker · Playwright · HTTPX · LLMs · OWASP API Security

🔗 [Repository](https://github.com/Hybrid-Translation-Project/Sentinel-Agent)

---

### 🧠 Personal Analyst

**Local AI-powered intelligent diary application**

A privacy-focused desktop application combining journaling,
local LLM inference, RAG and analytical querying.

The system uses a Smart Query Router to distinguish between
analytical queries, summaries and memory retrieval. Numerical
results are calculated through SQL rather than generated by the LLM.

**Tech:** Python · PyQt6 · SQLite · LanceDB · llama.cpp · Qwen2.5 · Docker

🔗 [Repository](https://github.com/g0rkm/Personal-analyst-diary-AI)
